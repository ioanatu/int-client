Build a client with React, TypeScript, Redux Toolkit, Vite. Requirements:

1. create a directory in `intNext` called `int-client` as a git repo, move this requrements file in there and add first commit with these requirements
2. create a basic client with above tech stack to fetch data from int-server backend, with caching, loading/error states
3. create list and detail views
4. use the generated types from backend
5. write basic tests with Vitest
6. use Material UI as component library
7. commit the code
8. add remote origin git@github.com:ioanatu/int-client.git and push code
